# ai-skills

Personal library of reusable AI agent skills. Plain [Agent Skills](https://agentskills.io) for Claude Code, Codex CLI, OpenCode, Cursor, GitHub Copilot and any harness the `skills` CLI supports, plus Claude Code and OpenCode agents built on them. Sources live in `.rulesync/`; [Rulesync](https://github.com/dyoshikawa/rulesync) generates the harness folders and the Claude Code plugin.

## Agents (Claude Code and OpenCode)

| Kind | Agents |
| --- | --- |
| Workers | `code-reviewer`, `qa-tester`, `developer`, `ci-investigator` |
| Orchestrators | `milestone-delivery`, `pr-shepherd`, `issue-resolver`, `inpi-watch`, `nfse-compliance` (`incident-responder` is a deprecated alias of `issue-resolver`) |
| Delivery flow | `business-analyst`, `tech-lead`, `readiness-reviewer`, `delivery-orchestrator`, `task-implementer` ([flow](docs/delivery-flow.md)) |

They ship with every skill as the `ai-skills` Claude Code plugin:

```text
/plugin marketplace add fbrissi/ai-skills
/plugin install ai-skills@fbrissi
```

Run an orchestrator as the main agent so it can delegate to the workers: `claude --agent ai-skills:milestone-delivery`. `nfse-compliance` can merge its own PRs, but only with auto-merge turned on (off by default), a human approval, and a risk rating within the limit. The same agents are generated for OpenCode in `plugins/ai-skills/opencode/agent/` (copy them into `.opencode/agent/`; run with `opencode run --agent <name>`). Details: [docs/claude-code-agents.md](docs/claude-code-agents.md).

## Install

Install with the [`skills` CLI](https://github.com/vercel-labs/skills) (requires Node.js 22.20+). It asks which skills, which harnesses, and whether to install in the current project or for your user:

```bash
npx skills add fbrissi/ai-skills
```

For your user, in every project:

```bash
npx skills add fbrissi/ai-skills -g
```

Without prompts (example: every skill for Claude Code and Codex, user-level):

```bash
npx skills add fbrissi/ai-skills -g -s '*' -a claude-code -a codex -y
```

Update or remove later:

```bash
npx skills update
```

```bash
npx skills check
```

```bash
npx skills remove
```

Pin a release with `npx skills add fbrissi/ai-skills@v0.1.0` (see [CHANGELOG.md](CHANGELOG.md) and [Releases](https://github.com/fbrissi/ai-skills/releases)).

Agent ids for `-a`: `claude-code`, `codex`, `opencode`, `cursor`, `github-copilot` ([full list](https://github.com/vercel-labs/skills/blob/main/docs/agents.md)). Codex, OpenCode, Cursor and Copilot share `.agents/skills/` in a project. Start a new session afterwards so the harness picks up the skills.

`pr-fix` and `review-changes` run a bash script and need `gh` and `jq`; on Windows use Git Bash or WSL. More in [requirements](docs/README.md#requirements).

| Harness | Invoke |
| --- | --- |
| Claude Code, Cursor, GitHub Copilot | `/pr-fix 123` |
| Codex CLI | `$pr-fix 123` |
| OpenCode | "use the pr-fix skill on PR 123" |

Projects that use Rulesync can pull the skills as a declarative source instead: see [docs/install-in-a-project.md](docs/install-in-a-project.md).

## Develop

Requires Node.js 22.22+. Edit only `.rulesync/`, `shared/` and `docs/`. `AGENTS.md`, `CLAUDE.md`, and the plugin in `plugins/ai-skills/` (except its `.claude-plugin/plugin.json`), including the OpenCode agents in `plugins/ai-skills/opencode/agent/`, are generated by `npm run generate` and committed; the harness folders (`.claude/`, `.agents/`, `.cursor/`, `.opencode/`, `.github/skills/`) are generated and gitignored.

```bash
npm install
```

```bash
npm run generate
```

```bash
npm run check
```

See [docs/contributing.md](docs/contributing.md) for the workflow, CI and releases.
